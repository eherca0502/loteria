## 📌 Descripción

**Lotería Mexicana** es un proyecto web desarrollado con HTML5, CSS3 y JavaScript que permite realizar partidas utilizando una baraja de cartas tradicionales.

La aplicación selecciona cartas aleatoriamente, anuncia sus nombres mediante síntesis de voz y permite controlar el ritmo de la partida. También incorpora un historial para consultar las cartas que han aparecido y un resumen con el orden en que fueron seleccionadas.

El proyecto busca combinar la tradición de este juego mexicano con una interfaz moderna y una experiencia de uso intuitiva.

## ✨ Características principales

- 🎴 **Selección aleatoria:** extracción de cartas durante la partida sin repetir las que ya salieron.
- 🔊 **Narración por voz:** anuncio del nombre de cada carta mediante la voz del navegador.
- ⏱️ **Velocidad personalizable:** ajuste del intervalo entre cartas.
- ▶️ **Control de partida:** iniciar, pausar, continuar y comenzar una nueva partida.
- 📋 **Historial en tiempo real:** visualización de las cartas que han aparecido.
- 📝 **Resumen de resultados:** consulta de todas las cartas en orden y opción para copiar la lista.
- 📱 **Interfaz adaptable:** diseño preparado para diferentes tamaños de pantalla.

## 🚀 Instalación y ejecución

### Requisitos

- Un navegador web moderno.
- Git, si deseas clonar el repositorio.
- Conexión a internet para clonar el proyecto.

### Ejecutar localmente

**1. Clonar el repositorio**

```bash
git clone https://github.com/eherca0502/loteria.git
```

**2. Entrar en la carpeta del proyecto**

```bash
cd loteria
```

**3. Abrir el proyecto**

Abre `index.html` en tu navegador o utiliza Visual Studio Code con la extensión Live Server para ejecutar la aplicación durante el desarrollo.

No se requiere instalar dependencias ni configurar una base de datos.

## 🎮 ¿Cómo jugar?

1. Abre la aplicación.
2. Pulsa **Iniciar partida** para comenzar a revelar cartas.
3. Ajusta la velocidad de acuerdo con el ritmo que prefieras.
4. Pausa o continúa la partida cuando lo necesites.
5. Consulta el historial para revisar las cartas que han salido.
6. Abre el resumen para verlas en orden o copiar la lista.
7. Inicia una nueva partida cuando quieras volver a jugar.
